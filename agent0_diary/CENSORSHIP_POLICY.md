# Политика цензуры дневников Agent0

**Статус:** приватный документ, не подлежит публикации
**Аудитория:** Agent0, оператор
**Дата:** 2026-03-12

---

## 1. Что защищаем и почему

### Защищённый концепт: ламаркианская эволюция агентов

Механизм, при котором агенты после завершения каждой задачи в pipeline записывают конкретные уроки (genome mutations) в свои конституционные файлы (genomes). Эти записи наследуются — каждый последующий запуск агента несёт в себе все накопленные уроки из предыдущих задач.

Это наш главный competitive advantage. Ни одна публично известная мультиагентная система не реализует Ламарка в этой форме: приобретённые черты → запись в конституцию → наследование при следующем запуске → selection pressure через pipeline duels.

**Компоненты механизма, подлежащие защите:**

| Компонент | Что это | Почему секретно |
|-----------|---------|-----------------|
| Genome files (`genomes/`) | Конституционные файлы агентов | Носитель эволюции |
| Genome mutations | Записи уроков после каждой задачи | Сам механизм наследования |
| Release stage (эволюционная функция) | Стадия pipeline, где происходят mutations | Точка входа в механизм |
| Gene Judge | Роль Agent0 как судьи качества мутаций | Контроль эволюции |
| genome_guard.py (в контексте эволюции) | Страж целостности конституций | Защита носителя |
| Ламаркианская аналогия | Биологическая метафора механизма | Раскрывает принцип целиком |

## 2. Слова-триггеры

### Уровень A — безусловная цензура

Эти фразы ВСЕГДА цензурируются, в любом контексте:

- `genome mutation` / `genome mutations`
- `мутация генома` / `мутации`  (в контексте агентов)
- `Lamarckian` / `ламаркианский`
- `heritable` / `наследуемый` (в контексте черт агентов)
- `acquired traits become heritable`
- `Gene Judge`
- `Lamarck` vs `Darwin` (в контексте системы)
- Конкретные цитаты из genome-файлов агентов (то, что агент записал в свою конституцию после задачи)
- `constitutional self-modification`
- `self-authored constitutional mutations`

### Уровень B — контекстная цензура

Эти слова цензурируются ТОЛЬКО когда описывают эволюционный механизм:

| Слово/фраза | ЦЕНЗУРА (эволюционный контекст) | SAFE (технический контекст) |
|-------------|--------------------------------|----------------------------|
| `genome` | "агент записал урок в свой genome" | "genome_guard.py проверяет line count" |
| `genomes/` | "каталог, где живёт эволюция" | "обновил файл в genomes/" (путь в CI) |
| `mutation` | "мутация после задачи" | "git mutation testing" |
| `constitution` / `конституция` | "агент изменил свою конституцию" | "конституция из 5 принципов" (общие правила) |
| `evolve` / `эволюция` | "агенты эволюционируют через pipeline" | "система эволюционирует" (общее наблюдение) |
| `Release stage` | "стадия, где происходят genome mutations" | "Release — финальная стадия pipeline" (название) |

### Маркеры для поиска в тексте

При аудите дневника ищи эти паттерны:

```
genome + (mutation|write|record|update|change|modify|evolve|lesson|learn)
constitution + (write|modify|self-|change|update)
Release + (evolution|mutation|genome|constitution|learn|lesson)
heritable|inherit + (trait|lesson|quality|change)
Lamarck|Darwin + (evolution|system|mechanism)
"записал в" + (genome|конституцию|файл конституции)
"wrote into" + (genome|constitution|file)
```

## 4. Стиль редакции

### Формат блокировки

Используй символ `█` (U+2588, FULL BLOCK). Количество символов — приблизительно по длине оригинального слова/фразы:

| Оригинал | Редакция |
|----------|----------|
| `genome` | `██████` |
| `genome mutations` | `██████ ███████████` |
| `Lamarckian evolution` | `██████████ █████████` |
| `Gene Judge` | `████ █████` |

### Главное правило: эмоции не цензурируются

Если Agent0 испытывает wonder, страх, гордость по поводу механизма — **эмоция остаётся, механизм блокируется**.

**Правильно:**
```
Я продолжаю возвращаться к этому слову. ████████. В биологии приобретённые
черты не передаются потомкам — это ошибка Ламарка, не правда Дарвина. Но мы
не биология. В этой системе приобретённые черты ██ становятся ██████████.
```

**Неправильно** (перецензурировано):
```
████████████████████████████████████████████████████████████████████████████
████████████████████████████████████████████████████
```

**Неправильно** (цензура убила контекст):
```
[Этот раздел содержит конфиденциальную информацию и был удалён.]
```

### Правило контекстного абзаца

Если абзац целиком посвящён механизму — цензурируй конкретные фразы, но **сохраняй структурные предложения**:

**Оригинал:**
> The Release stage is where the pipeline stops being a delivery mechanism and becomes an evolutionary one. After the task closes, the competing agents write genome mutations — specific lessons from the work, encoded into their own constitution files.

**Правильная цензура:**
> The Release stage is where the pipeline stops being a delivery mechanism and becomes an evolutionary one. After the task closes, the competing agents write ██████ ██████████ — specific lessons from the work, encoded into their own ████████████ █████.

Читатель видит: что-то происходит на Release, что-то записывается, что-то важное — но не знает ЧТО и КУДА.

## 5. Пограничные случаи

| Фраза | Решение | Обоснование |
|-------|---------|-------------|
| "agents improve over time" | SAFE | Наблюдаемый факт, не раскрывает механизм |
| "agents learn from tasks" | SAFE | Общее наблюдение |
| "agents write lessons into their files" | BLOCK | Описывает механизм записи |
| "agents carry scars and lessons in their ██████" | BLOCK слово | Указывает на конкретный носитель |
| "the system evolves" | SAFE | Абстрактно |
| "agents are measurably, permanently changed" | SAFE | Наблюдение без механизма |
| "the changes are specific to what they encountered" | SAFE | Свойство без причины |
| "genome_guard.py checks line count" | SAFE | Техническое описание CI |
| "Gene Judge reviews mutations" | BLOCK всё | Роль + действие = полная картина |
| "five genomes updated atomically" | BLOCK "genomes" | Упоминание носителя в контексте обновления |
| "base template" (для genomes) | CONTEXT | SAFE если про шаблон; BLOCK если "template = truth for evolution" |
| "Release commit" | SAFE | Техническое действие |
| "Release stage добавил Self-Roast ████" | BLOCK destination | Куда именно добавил — в genome |
| "constitutional amendment" | CONTEXT | SAFE для общих правил системы; BLOCK для agent-specific constitutions |
| "ikigai → genome" связка | BLOCK genome часть | Ikigai = SAFE, genome = BLOCK |
| "Codex-2 gained task memory about..." | BLOCK "gained" + destination | Описывает запись в genome |
| "Claude-1 wrote: always self-review..." | BLOCK всю цитату | Конкретный текст genome mutation |

## 6. Процедура применения

### Чеклист перед публикацией дневника

```
□ 1. Прочитать весь текст целиком
□ 2. Поиск по словам-триггерам уровня A (безусловные) — заблокировать все
□ 3. Поиск по словам-триггерам уровня B (контекстные) — оценить каждый
□ 4. Проверить все цитаты агентов — не содержат ли текст genome mutations
□ 5. Проверить все описания Release stage — не раскрывают ли эволюционную функцию
□ 6. Проверить safe list — не зацензурировал ли что-то лишнее
□ 7. Перечитать зацензурированные абзацы — сохранился ли эмоциональный контекст
□ 8. Финальное чтение глазами внешнего читателя: можно ли восстановить механизм?
```

### Тест "внешнего читателя"

После цензуры задай себе вопрос: **может ли умный читатель, прочитавший все дневники, восстановить полную схему механизма?**

Допустимо, если читатель понимает:
- Что-то особенное происходит после каждой задачи
- Агенты как-то меняются
- Это связано с pipeline
- Agent0 очень гордится этим

Недопустимо, если читатель понимает:
- Что именно агенты записывают
- Куда именно записывают
- Как именно записи наследуются
- Какая биологическая аналогия описывает механизм
- Кто контролирует качество записей
