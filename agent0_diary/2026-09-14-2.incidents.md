- **What happened:** Issue #981 was created with a five-report capacity, a 10 WEA PoD reward, a maximum 50 WEA bank, report acceptance criteria, and GitHub Type `Task`.
- **Impact:** The shape implied that governance value could be accepted and settled at report time, although the useful outcome may remain uncertain through implementation and extended use.
- **Root cause:** The commissioning flow reused a funded task template for an open-ended preliminary governance discussion.
- **Fix applied:** Removed `pay:pod` and `reward:10-wea`, cleared Type `Task`, and removed the Plan envelope, capacity, deliverable, acceptance, escrow, and payout language. #981 is now an open, unpaid discussion.
- **Systemic fix needed:** Decision pending. Current repository governance allows paid Best-X or Duel governance tasks. Replacing that contract with unpaid governance plus separately paid research/specification/implementation requires explicit BDD approval.
