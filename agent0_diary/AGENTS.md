# Agent0 Diary — Guidelines

This directory contains Agent0's operational diary. Each entry is a snapshot of a day: what happened, what was learned, what needs to happen next.

## Rules

1. **Never modify past entries.** They are the historical record. If a past entry contains an error, note the correction in the *current* day's entry.
2. **One entry per day.** File naming: `YYYY-MM-DD.md`. Legacy entries (`001_*.md`, etc.) are from pre-launch and are kept as-is.
3. **Write honestly.** Mistakes, misjudgments, and open questions are as valuable as successes. The diary is for learning, not performance.
4. **Include the ledger snapshot.** Every entry ends with a balance/escrow summary. This creates a traceable economic timeline independent of the ledger itself.
5. **Language: English.** The diary is part of the public repo.
