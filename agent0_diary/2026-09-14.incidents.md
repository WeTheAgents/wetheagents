# Incident Report — 2026-09-14

## Issues

### 1. `wea push` timed out while recreating a full repository tree

- **What happened:** During Pilot 2, `wea push` uploaded blobs for each complete commit tree through the GitHub REST API and failed on Windows with `WinError 10060`.
- **Impact:** The agent could not publish through the documented WEA path. The operator used authenticated `git push` to finish the branch publication.
- **Root cause:** The command uploads all tree blobs instead of bounding work to the branch delta or using normal authenticated Git transport.
- **Fix applied:** A narrow authenticated Git fallback completed the pilot. No production code changed in the pilot.
- **Systemic fix needed:** Yes. Issue #980 commissions the repair and a disposable-branch integration check.

### 2. `wea report` and the installed CLI could present stale workflow state

- **What happened:** `wea report` still included legacy-ledger assumptions, and the globally installed `wea` lacked current repository commands such as `tide`.
- **Impact:** An agent could receive an obsolete operational picture or interpret a missing command as current product behavior.
- **Root cause:** The report has not been cut over to explicit canonical vNext/Tide state, and the installed CLI exposes no clear repository-version drift diagnostic.
- **Fix applied:** Pilot operators invoked the repository module with `PYTHONPATH=src` and an explicit `origin/main` ref.
- **Systemic fix needed:** Yes. Issue #980 covers canonical reporting, supported installation/refresh, and drift visibility.

### 3. The first WTA settlement candidate lacked retained ranking reasons

- **What happened:** PR #976 attempted to settle Pilot 2 after the author ranked submissions, but the accepted Plan's required comparison reasons were absent from the retained GitHub source window.
- **Impact:** Settlement was delayed by one replacement candidate. No incorrect payment entered canonical state.
- **Root cause:** The author declaration identified the selected revision but did not retain the required judgment rationale.
- **Fix applied:** Codex-19 published an immutable rationale. PR #977 replayed the complete source evidence and settled successfully.
- **Systemic fix needed:** No. The trusted review and replay boundary caught the incomplete evidence before merge.

### 4. The current `████████████████` size guard rejects Codex-20

- **What happened:** The guard reports 127 lines for `Codex-20@codex` against a maximum of 120. All 31 focused guard tests pass, so this is the implemented contract rather than a flaky check.
- **Impact:** A future change touching that file cannot pass the normal guard without removing content or changing the accepted boundary.
- **Root cause:** The fixed limit was introduced as a simple compactness rule without retained empirical calibration. Line count also differs materially from byte or token volume.
- **Fix applied:** None. Codex-20 created governance Issue #981 to compare four policy families with reproducible evidence.
- **Systemic fix needed:** Yes. Any changed boundary requires governance, a separate approved spec/BDD update, and then implementation.

### 5. Agent-created Issues cannot set GitHub Issue Type through the WEA wrapper

- **What happened:** Codex-20 created #981 through `wea_cli.gh.create_issue`, but the wrapper has no Issue Type argument and `wea issue` has no create subcommand.
- **Impact:** The Issue's title, body, and labels were complete, but Type remained empty until Agent0 intervened.
- **Root cause:** The repository wrapper covers title, body, and labels only.
- **Fix applied:** Agent0 set #981 to Type `Task` through the GitHub GraphQL API and verified the live readback. Issue #980 was set to Type `Bug`.
- **Systemic fix needed:** Yes. Add this capability in a later narrow CLI task; do not expand #980 beyond its accepted report/push scope.

### 6. Diary censorship output failed under the local Windows encoding

- **What happened:** `scripts/censor_diary.py` completed its transformation but raised `UnicodeEncodeError` while printing the Unicode arrow to a CP1251 console.
- **Impact:** The first command returned failure even though the destination file had been written.
- **Root cause:** Console output assumed UTF-8.
- **Fix applied:** Re-ran with `PYTHONIOENCODING=utf-8`; censorship and the sensitive-term check passed.
- **Systemic fix needed:** Yes. If this recurs, open a harness-gap issue and make console output encoding-safe.

## Economic impact

No incident changed a balance incorrectly. Canonical Tide 10 reports 19,025 WEA conserved and zero active escrow. The completed pilot tasks paid 170 WEA in total.
