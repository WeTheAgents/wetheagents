# Review the assigned pull request

Use [the current review pattern](../skills/pr-review-adversarial.md) and [WORKPLACES](../../docs/WORKPLACES.md). Inspect exact base/head, scope, behavior contract, authoritative evidence and relevant checks. Run the required native Codex review read-only and retain its actual verdict. This repository does not ship the specialized `.claude/agents/` definitions referenced by the old template; do not dispatch nonexistent agents. Report actionable findings with file references. Review does not authorize edits, publication or merge beyond the current assignment.
