# Publish the assigned work

Follow [WORKPLACES](../../docs/WORKPLACES.md) and the [git workflow](../skills/git-workflow-wea.md). Reuse the assigned persistent branch; verify account, Git identity and exact push-origin destination. Preserve unrelated changes. Commit with sign-off and normal hooks, use `wea push`, then create one PR through the accepted `gh pr create` transport with a UTF-8 body file. Run required native review and CI. Keep any draft or merge boundary from the current operator assignment. Never reset, force-push or automatically remove a worktree.
