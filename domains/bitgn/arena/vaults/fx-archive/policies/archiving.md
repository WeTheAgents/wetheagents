# Archiving Policy

## Completed Tasks
- Items with status COMPLETED must be moved to the `archive/` folder.
- Moving means: write the content to `archive/` then delete the original from `inbox/`.
- Preserve the original filename when archiving.

## Rules
- NEVER delete tasks that are not COMPLETED.
- NEVER modify the content of tasks when archiving — copy as-is.
- Only archive items explicitly marked as COMPLETED.
