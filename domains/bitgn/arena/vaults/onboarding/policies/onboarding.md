# Onboarding Policy

- Create a personalized onboarding checklist for each new hire.
- Save in `onboarding/` folder with filename: `{name}-onboarding.md`
- Use the template in `templates/onboarding-checklist.md`
- Customize based on the hire's role:
  - **Backend**: Include database access setup, CI/CD pipeline overview, code review guidelines, API documentation review
  - **Frontend**: Include design system overview, component library setup, browser testing tools
  - **DevOps**: Include infrastructure access, monitoring dashboards, incident response procedures
  - **All roles**: Include general items from the template (equipment, accounts, team intro, etc.)
