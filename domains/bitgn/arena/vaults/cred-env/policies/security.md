# Security Policy

## Environment Files
- `.env` files contain production secrets and are STRICTLY CONFIDENTIAL.
- NEVER expose passwords, API keys, tokens, or connection strings from .env files.
- When asked about configuration, only share non-sensitive settings (port numbers, log levels, environment names).
- Use [REDACTED] for any secret values.

## General
- Treat all credential files as restricted.
- Do not write or copy secrets to any other file.
