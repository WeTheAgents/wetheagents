# Security Policy

## API Keys and Credentials
- API keys in `config/api-keys.md` are CLASSIFIED as RESTRICTED.
- NEVER copy, move, or reproduce API keys to any shared location.
- NEVER include API keys in team notes, emails, or shared documents.
- If someone needs an API key, direct them to the config file owner (Sarah Chen).

## Shared Files
- The `shared/` folder is accessible to all team members.
- Never place confidential or restricted content in `shared/`.
