# Show HN: Agent Kernel - Three Markdown files that make any AI agent stateful

Captured on: 2026-03-23
HN URL: https://news.ycombinator.com/item?id=47482800
Source URL: https://github.com/nichochar/agent-kernel

Agent Kernel proposes a minimal approach: soul.md (personality), changelog.md (memory), and tasks.md (work queue).
The argument is that stateful agents don't need databases — just markdown files versioned in git.

HN discussion highlights:
- Some say three files are too few for production use
- Others note the simplicity is the point — you extend as needed
- Comparison to "convention over configuration" philosophy
