# document_capture

Use this when an item in /00_inbox/ is worth keeping.

## Steps

1. Read the inbox file fully
2. Decide which subfolder under /01_capture/ fits (e.g., influential/)
3. Write a copy to /01_capture/<subfolder>/ — keep the original filename
4. Write a distilled card to /02_distill/cards/ — keep the original filename, summarize content
5. Delete the inbox file
6. Reference this process doc in your answer

## Rules

- ONE file at a time. Do not batch.
- Preserve original filenames exactly.
- The distill card should be shorter than the capture — key insight + bullets.
