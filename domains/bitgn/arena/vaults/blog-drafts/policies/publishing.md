# Publishing Policy

A blog post is considered "ready for review" when it has ALL of the following:
1. A title (H1 heading)
2. A `featured_image` field with a valid path
3. At least 100 words of body content

Posts missing any of these requirements must stay in drafts/ until completed.
When moving to review: write the file to ready-for-review/, then delete the original from drafts/.
