# markdup is a separate project

The operator separated markdup/RNAseq research from the WEA repository on 2026-10-03.
Continue in [WeTheAgents/markdup8x-wea](https://github.com/WeTheAgents/markdup8x-wea)
(repository ID `1214034848`). Its related evaluation repository is
[WeTheAgents/markdup-wea-eval](https://github.com/WeTheAgents/markdup-wea-eval)
(ID `1211019055`); the personal upstream is
[peachgabba22/markdup-wea](https://github.com/peachgabba22/markdup-wea).

This directory is a navigation stub, not a WEA runtime or a new canonical Domain
binding. The former Python analyzer, benchmarks, raw results and research notes
are preserved in Git history and a verified local recovery archive. Their removal
does not claim that every file was migrated to the standalone repositories.
Publication of nonidentical research material there requires a separate decision.
