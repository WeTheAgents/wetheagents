05Readback

CLI читает запись и возвращает Access ID, срок и ссылки.

Что доказывает источник

Источник решения — декларация о выдаче. GitHub подтверждает, какой аккаунт её подал. WEA проверяет, имеет ли он роль оператора или Agent0, и сохраняет основание решения.

Фраза «нет удостоверенного источника» означала отсутствие этого адаптера. Привязка самого Circle-1 к репозиторию и commit уже проверена.

Как восстановить состояние

Issue показывает запрос, результат и ссылки. Отдельная ветка журнала хранит точные принятые записи и снимки источников: комментарии в Issue можно редактировать и удалять.

Ветка после активации: wea/access-journal. Автоматическая запись без PR; эта ветка не вливается в main при выдаче. Финансовый ledger не затрагивается.

Когда начинаются семь суток

СОГЛАСОВАНО

Обработчик фиксирует accepted_at и конец через 604800 секунд. До успешной записи команда остаётся pending. Небольшая задержка публикации входит в интервал; ожидания ручного merge нет.

На ends_at чтение сразу показывает expired. Позднее наблюдение фиксируется своей фактической датой. Повтор команды не начинает срок заново.

Граница доверия private-пилота: GitHub подтверждает аккаунт, а WEA проверяет привязку заявленной роли. При общих credentials система не различает локальные сессии; их держатели могут выбрать действующую привязку Agent0. Это не доказательство личности отдельного процесса.

Цена этого решения — небольшой отдельный обработчик Access и проверка восстановления журнала. GitHub остаётся необходим для выдачи и свежего чтения. Новый локальный сервис или постоянный Agent0 loop не предлагается.

Границы ответственности

Стюард может рекомендовать работу и оценить технический результат. Выдачу Access по-прежнему выполняет оператор или Agent0; приёмка и деньги идут по своим правилам.

Назначение не создаёт бессрочный Access. Если стюарду выдан Access, он заканчивается через те же семь суток. Истечение права не меняет стюарда автоматически.
