## REVIEW

Независимые агенты проверяли читаемость, Contract, состояния и доказательства. Замечания не меняли одобренное поведение без решения оператора. `[REVIEW]`

| ID | Finding | Решение |
| --- | --- | --- |
| EV-REVIEW-01 | Готовность была заявлена до свежих команд и review. | `verification.md` требует статусы `Complete` и точные результаты до сборки. |
| EV-REVIEW-02 | HTML отстал от Markdown. | Финальная сборка повторяется дважды; manifest и hash сверяются с файлами. |
| EV-REVIEW-03 | Метки источников не вели к переносимым доказательствам. | Добавлены этот раздел, ссылки в метках, полный хеш и снимок исходного handoff. |
| EV-REVIEW-04 | Renderer не показывал закрытые OD-24…OD-27. | Интерактивно остаются только нерешённые вопросы по прямому требованию оператора; четыре одобренных результата сохранены в `CHAT` выше. |
| EV-REVIEW-05 | Handoff ссылался на ещё не созданный коммит. | Пакет фиксируется коммитом с указанной темой; следующий Agent0 сначала проверяет ветку и манифест пакета. Точный SHA сообщается при передаче, потому что коммит не может включать собственный SHA. |
| EV-REVIEW-06 | Старый Contract не закреплял исполняемый код. | Contract и bootstrap хранят rules hash, Tide interface version и executor manifest hash; старый executor неизменяем и тестируется после установки нового. |
| EV-REVIEW-07 | Не было восстановления нефинансового состояния. | Добавлен только дополняемый `replay_repair`; исходные события и WEA не меняются. |
| EV-REVIEW-08 | Два подтверждения контролирует одна учётная запись GitHub. | Риск принят как одобренная граница первого этапа: это двухшаговая процедурная проверка, не независимые ключи; документация больше не утверждает обратное. |
| EV-REVIEW-09 | Access мог истечь только внутри WEA, оставив GitHub permission. | Access определён как право WEA; внешний grant/revoke ручной и имеет отдельный reconciliation result. |
| EV-REVIEW-10 | План не называл надёжный источник edit revisions. | Живой GraphQL check подтвердил `UserContentEdit.id`; адаптер обязан читать все страницы, а неполная история блокирует цикл. |
| EV-REVIEW-11 | Hello World import мог повторно начислить 42 WEA. | Импортированный account получает использованный key без mint; 42 WEA доступно только новому account после переключения. |
| EV-REVIEW-12 | Переключение не останавливало уже запущенные пути записи v1. | Добавлены классификация путей, остановка новых запусков, ожидание очереди, зафиксированный HEAD, общая блокировка, закрытие прежних учётных данных и epoch guards. |
| EV-REVIEW-13 | Формулировка паузы могла запретить разрешение проверки, законченной до паузы. | Spec, schema и tasks одинаково разрешают только остановку и полный своевременный набор проверки, завершённый до паузы. |
