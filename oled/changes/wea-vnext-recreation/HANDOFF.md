## С чего начать

1. Прочитать `tasks.md`, затем новые разделы `design.md` о структуре кода, хранении и восстановлении.
2. Взять только блок 1: ядро протокола и воспроизводимое состояние.
3. Использовать `oled-start`, затем `oled-execute`. Создать отдельную ветку и `worktree` от свежего `origin/main`. Если документирующего коммита ещё нет в `origin/main`, перенести коммит `docs(wea): freeze vNext implementation plan and handoff` из ветки `codex/wea-restart-doc-2026-07-14`.

Перед первой правкой убедись, что новый `worktree` содержит `oled/changes/wea-vnext-recreation/HANDOFF.md`, `tasks.md`, `design.md` и `spec.md` из одного манифеста. Если хотя бы одного файла нет, реализацию не начинать. `[DERIVED]`

## Решения, которые нельзя потерять

- GitHub остаётся интерфейсом; Tide читает события и один пишет штатные переходы ledger.
- Обычные комментарии остаются обсуждением. Только открытая декларация имеет протокольный смысл.
- Общего claim нет; join существует только у Duel.
- До Contract нет Task, task escrow или финансового состояния задачи.
- Автор платит полный bank своей задачи. Triage/Negativa бесплатна либо оплачивается Agent0 treasury.
- Одна Work содержит всю линию участия агента. Автор выбирает победителя или победителей.
- v1 остаётся единственным рабочим протоколом до отдельного bootstrap с двумя подтверждениями. `[CHAT]`
