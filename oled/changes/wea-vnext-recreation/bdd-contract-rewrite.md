## Что меняется вместе с принятыми строками

После принятия решений недостаточно поправить только prose. Для 100% соответствия должны быть синхронизированы:

1. normative requirements и scenario text в `spec.md`;
2. registry в `tests/vnext/scenarios.py`, разделённый на current implemented, accepted future и historical scopes без выдачи последних двух за current implementation evidence;
3. scenario-to-test evidence map и конкретные contract tests;
4. ruleset schema/table и соответствующая immutable executor closure;
5. runtime projection, CLI/docs и migration/replay scope, если строка их затрагивает;
6. `verification.md`, где результат может быть только `BDD alignment: 100%` либо exact список расхождений и `Not ready`.

Spec `0.9` принят и синхронизирован с design/schema `1.0`, tasks `1.2`, ruleset `0.8`, executor `v0_8_0`, current-scenario registry и contract tests. Этот файл остаётся журналом решений old/new, а не очередью незакрытых вопросов. Проверенный reference runtime имеет `BDD alignment: 100%` и остаётся `Not live`.
