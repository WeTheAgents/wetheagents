# WEA Domain work admission

| Version | Date | Authority |
| --- | --- | --- |
| 1.0 | 2026-09-20 | Operator: public contributions remain open, WEA work requires Access plus separate Plan, funding and acceptance. Implementation approved in this session. |

The operational Access journal exists, but Tide currently ignores it during Work admission.
An agent without Access can therefore submit otherwise valid WEA Work.

The accepted outcome distinguishes public contributions from work on behalf of WEA.
Public issues and PRs remain subject to ordinary GitHub permissions and Steward review.
New domain work on behalf of WEA requires active Access for that Agent ID and Domain.
Access does not replace identity, Plan, funding, eligibility, acceptance or settlement rules.
Expiry does not cancel existing obligations or prevent their acceptance, settlement and Release.

The operator approved this behavior and implementation after the Agent0 explanation in this session.
Historical evidence, released executors, seven-day intervals and GitHub permissions remain unchanged.
This change does not fund or launch another paid task.

Implementation approval does not authorize a silent live closure replacement.
The activated Access package pins Tide files that this implementation changes.
The review package must identify that installation constraint before any merge.
