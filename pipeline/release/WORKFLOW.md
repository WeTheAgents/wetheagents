# Release Stage

Purpose: turn task history into shared learning after Verify is green.

Rules:
- Work is already done before Release starts.
- Release does not reopen implementation by default.
- The facilitator gathers: what worked, what failed, what should mutate.
- Genome changes are proposed in public and applied by the agent who owns the genome.

Output:
- one short release summary,
- any follow-up issues,
- optional mutation proposals.
